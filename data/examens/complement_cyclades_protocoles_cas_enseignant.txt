=== CYCLADES — PROTOCOLES : CAS PRATIQUES DE L'ENSEIGNANT (mémo national « enseignant EPS » de Cyclades et guides académiques) ===
Sources : mémo « Enseignant EPS » de l'application Cyclades (version 2.0) et guide de saisie des notes diffusé par une autre académie. Les demandes à la commission passent par l'inspection pédagogique et la DEC de chaque académie.

### [SITUATION: PROTOCOLE CYCLADES CRÉÉ AVEC LE MAUVAIS GROUPE D'ÉLÈVES — LE CHAMP « GROUPE ÉLÈVE » N'EST PLUS MODIFIABLE]
- Mots-clés : groupe élève, champ grisé, non modifiable, mauvais groupe, erreur de groupe, supprimer le protocole, recréer le protocole.
- Formulations courantes des collègues : je me suis trompé de groupe d'élèves en créant mon protocole ; le groupe élève n'est plus modifiable ; comment changer le groupe d'un protocole ; le champ groupe est grisé.
- Dans Cyclades, le champ « groupe élève » d'un protocole n'est plus modifiable une fois le protocole créé.
- Correction : supprimer le protocole, puis le recréer avec le bon groupe élève.
- Si les protocoles ont déjà été transmis à la commission, cette suppression n'est plus possible directement : voir la fiche « modifier un protocole après transmission ».
- Si seuls quelques élèves sont mal placés (et non tout le groupe), il n'est pas nécessaire de supprimer : les déplacer dans le bon protocole par le menu [EPS] / [Associer les élèves à un protocole].

### [SITUATION: LE GROUPE ÉLÈVE N'EST PAS RENSEIGNÉ DANS LE LOGICIEL DE SCOLARITÉ — QUE METTRE DANS LE PROTOCOLE ?]
- Mots-clés : groupe élève absent, logiciel de scolarité, nom de groupe libre, répartition manuelle des candidats.
- Formulations courantes des collègues : je n'ai pas de groupe élève à choisir ; quel groupe mettre dans mon protocole ; les groupes ne remontent pas.
- Deux possibilités : le chef d'établissement importe un fichier de groupes pour une affectation automatique (dans une académie iPackEPS, c'est le fichier exporté d'iPackEPS) ; ou l'enseignant saisit un nom de groupe élève parlant pour lui, puis répartit lui-même les candidats ensuite, par le menu [EPS] / [Associer les élèves à un protocole].

### [SITUATION: L'APSA QUE J'ENSEIGNE N'EST PAS DANS LA LISTE QUAND JE CRÉE MON PROTOCOLE DANS CYCLADES]
- Mots-clés : APSA manquante, APSA absente de la liste, activité introuvable, liste des APSA Cyclades, commission académique.
- Formulations courantes des collègues : mon activité n'apparaît pas dans Cyclades ; l'APSA n'est pas dans la liste déroulante ; je ne trouve pas mon activité pour créer le protocole.
- La liste de Cyclades propose les APSA validées par la commission académique pour l'établissement.
- L'enseignant prévient son chef d'établissement, qui contacte la commission académique (ou le gestionnaire des examens).
- Vérification à faire d'abord dans iPackEPS : l'APSA doit être déclarée « certificative » pour la voie concernée ([Dossiers] > [Dossier EPS] > [APSA]) et son référentiel doit être déposé et validé ([Dossiers] > [Dossier Certificatif] > dépôt des référentiels). Une APSA non déclarée ou au référentiel refusé n'est pas proposée.
- Exception : pour un protocole ADAPTÉ, toutes les APSA de Cyclades sont proposées, sans limitation.

### [SITUATION: MODIFIER OU CRÉER UN PROTOCOLE APRÈS LA TRANSMISSION À LA COMMISSION]
- Mots-clés : protocoles transmis, protocoles validés, modifier après transmission, réouverture, dévalider, protocole adapté, inspection pédagogique régionale.
- Formulations courantes des collègues : on a transmis nos protocoles et on veut en modifier un ; peut-on encore changer une APSA ; comment rouvrir les protocoles ; je ne peux créer que de l'adapté.
- Après la transmission, seuls les protocoles ADAPTÉS peuvent encore être créés ou modifiés.
- Pour modifier ou créer un protocole standard, le chef d'établissement doit demander une réouverture à l'inspection pédagogique régionale (la commission dévalide temporairement les protocoles).
- Une fois la modification faite : menu [EPS] / [Tableau de bord], retransmettre les protocoles ; la commission les valide à nouveau.

### [SITUATION: L'ADRESSE MAIL DU PROFESSEUR EST GRISÉE DANS LE PROTOCOLE — PROTOCOLE CRÉÉ POUR UN COLLÈGUE]
- Mots-clés : email professeur grisé, protocole d'un collègue, réaffecter le protocole, chef d'établissement.
- Formulations courantes des collègues : j'ai créé le protocole de mon collègue, il est à mon nom ; je ne peux pas changer l'adresse mail ; mon collègue ne voit pas son lot.
- Le champ de l'adresse mail du professeur n'est pas modifiable par l'enseignant : le protocole porte l'adresse de celui qui l'a créé.
- C'est le chef d'établissement qui réaffecte le protocole au bon enseignant : Cyclades, menu [EPS] / [Contrôler / Réaffecter des protocoles].

### [SITUATION: RETIRER UN ÉLÈVE D'UN PROTOCOLE CRÉÉ PAR UN AUTRE ENSEIGNANT]
- Mots-clés : retirer un élève, protocole d'un autre professeur, glisser-déposer.
- Formulations courantes des collègues : un de mes élèves est dans le protocole d'un collègue ; comment récupérer un élève placé ailleurs.
- On ne peut pas simplement le retirer : il faut le déplacer, par glisser-déposer, vers un de ses propres protocoles (menu [EPS] / [Associer les élèves à un protocole]).

### [SITUATION: SANTORIN — MA NOTE AVEC UNE VIRGULE N'EST PAS ACCEPTÉE (EXEMPLE : 4,5)]
- Mots-clés : virgule, décimale, point, 4,5, 6,5, note refusée, case vide, note non prise en compte, touche Entrée.
- Formulations courantes des collègues : Santorin refuse ma note 4,5 ; la case reste vide quand je tape une note à virgule ; ma note décimale n'est pas prise ; je n'arrive pas à mettre un demi-point.
- Dans Santorin, une décimale se tape avec un POINT et non avec une virgule : taper 4.5 et non 4,5.
- Après la saisie au clavier, appuyer sur la touche Entrée pour valider la valeur, puis cliquer sur [Enregistrer].
- On peut aussi choisir la valeur dans la liste déroulante de la case.

### [SITUATION: SANTORIN — CORRIGER UNE NOTE DÉJÀ SAISIE : FAUT-IL CLIQUER SUR « RÉINITIALISER » ?]
- Mots-clés : corriger une note, erreur de saisie, modifier une note, réinitialiser, tout effacer, lot verrouillé, déverrouiller.
- Formulations courantes des collègues : je me suis trompé sur une note ; puis-je cliquer sur réinitialiser ; comment modifier une note déjà enregistrée ; j'ai saisi la mauvaise note pour un élève.
- Pour corriger UNE note : rouvrir la fiche de l'élève ([Éditer la notation]), remplacer la valeur erronée, puis [Enregistrer]. C'est possible tant que le lot n'est pas verrouillé.
- NE PAS cliquer sur « Réinitialiser » si plusieurs APSA sont déjà saisies : ce bouton remet à zéro TOUTE la saisie de l'élève, et pas seulement la note fausse.
- « Réinitialiser » ne sert que si la fiche de l'élève est bloquée et qu'il faut repartir de zéro pour cet élève.
- Si le lot est déjà verrouillé : seul le chef d'établissement peut le déverrouiller (Santorin, [Correction] > [Liste des lots], clic sur le cadenas).

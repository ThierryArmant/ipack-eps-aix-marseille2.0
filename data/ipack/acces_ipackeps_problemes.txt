=== IMPOSSIBLE D'ACCÉDER À iPackEPS — DIAGNOSTIC OFFICIEL (site iPackEPS, article « En cas d'impossibilité d'accéder à iPackEPS ») ===
Repère : Dans l'académie d'Aix-Marseille, le portail est ESTEREL : iPackEPS se trouve dans le bloc « Enquête et pilotage » ; s'il n'apparaît pas, bouton « Aide » > « Synchro manuelle » > « Rafraîchir la page ». Ailleurs, dans le nouveau portail ARENA (2025), iPackEPS se trouve dans la rubrique « Structures et personnels ». Dans l'ancien portail, il était dans « Enquêtes et Pilotage » > « Pilotage académique ». Le correspondant académique iPackEPS de votre académie est l'interlocuteur à contacter.
Réponse directe — lien iPackEPS absent du portail : à Aix-Marseille, portail ESTEREL, bloc « Enquête et pilotage » ; s'il n'apparaît pas : [Aide] > [Synchro manuelle] > [Rafraîchir la page]. Sinon, vérifier le portail externe (« externet »), la discipline EPS dans l'annuaire et l'identifiant utilisé (ancien / nouveau), puis contacter le correspondant académique iPackEPS.
Réponse directe — accès à certains modules ou menus seulement (dossier certificatif, menus absents) : ce n'est pas un problème de connexion ; voir [Ma Fiche Professeur] > [Fonctions] (fiche « Ma Fiche Professeur »).

### [SITUATION: JE NE VOIS PAS LE LIEN iPackEPS – PROFESSEUR DANS ARENA]
- Mots-clés : lien absent, iPackEPS invisible, ARENA, externet, intranet, clé OTP, portail premier degré, discipline EPS, annuaire, deux identifiants, contractuel titularisé.
- Formulations courantes des collègues : iPackEPS n'apparaît pas dans mon ARENA ; je ne trouve pas iPackEPS ; je viens d'être titularisé et je n'ai plus iPackEPS ; depuis le poste du secrétariat je ne le vois pas.
- Q : Je ne vois pas le lien [iPackEPS – Professeur] dans mon portail ARENA.
- R, piste 1 — mauvais portail ARENA : le module professeur n'est accessible que par le portail externe (« externet »). Par un accès intranet (poste du chef d'établissement, accès par clé OTP), le lien n'apparaît pas. Certaines académies ont aussi plusieurs portails (premier degré, second degré) : il faut le portail du second degré.
- R, piste 2 — vous n'êtes pas reconnu comme enseignant d'EPS : ARENA n'affiche iPackEPS que si la fiche de l'annuaire des personnels du rectorat indique la discipline EPS. Ces fiches peuvent être erronées en début d'année : contacter le correspondant académique iPackEPS.
- R, piste 3 — mauvais identifiant : certains enseignants ont deux identifiants académiques (ancien contractuel titularisé, pour qui une nouvelle fiche a été créée). Avec l'ancien identifiant, iPackEPS n'apparaît pas : se connecter avec le nouveau.

### [SITUATION: J'ACCÈDE À iPackEPS MAIS MON ÉTABLISSEMENT N'APPARAÎT PAS (OU C'EST MON ANCIEN ÉTABLISSEMENT)]
- Mots-clés : aucun établissement proposé, ancien établissement, page vierge, adresse mail inconnue, TZR, contractuel, établissement privé, RNE, login.
- Formulations courantes des collègues : aucun établissement dans la liste ; iPackEPS me propose mon lycée de l'an dernier ; page blanche à l'ouverture ; je suis TZR et je ne vois pas mon établissement.
- Q : J'arrive bien dans iPackEPS – Professeur, mais mon établissement n'apparaît pas.
- R, explication : ARENA vous reconnaît comme professeur d'EPS, mais votre adresse mail n'est pas connue dans les bases d'iPackEPS.
- R, piste 1 — mauvais compte : avec deux identifiants académiques (cas de TZR ou de contractuels ayant reçu un nouveau compte), l'ancien identifiant renvoie à l'ancien établissement. Utiliser le nouvel identifiant.
- R, piste 2 — établissement inconnu d'iPackEPS : certains établissements privés n'ont pas été importés, d'où une page vierge.
- R, piste 3 — enseignant inconnu d'iPackEPS : affectation pas encore remontée dans les bases en début d'année.
- R, dans les trois cas : écrire au correspondant académique iPackEPS en donnant l'identifiant utilisé pour se connecter à ARENA et le RNE de l'établissement d'affectation, pour qu'il fasse vérifier par les services informatiques.

### [SITUATION: ERREUR 403 FORBIDDEN, NOT FOUND OU 400 BAD REQUEST EN CLIQUANT SUR iPackEPS]
- Mots-clés : Error 403, Forbidden, Not Found, Error 400, Bad Request, cache, changer de navigateur, gérer mes favoris, recréer le favori.
- Formulations courantes des collègues : erreur 403 en ouvrant iPackEPS ; bad request ; page not found depuis ARENA ; ça marchait hier et plus aujourd'hui.
- Q : En cliquant sur le lien d'accès, mon navigateur affiche « Error 403 – Forbidden », « NOT FOUND » ou « Error 400 Bad Request ».
- R : des mises à jour d'ARENA ont rendu certains accès instables. Trois essais, dans l'ordre :
- R1 : changer de navigateur.
- R2 : vider le cache (raccourci Ctrl + Maj + Suppr, puis « supprimer les données de navigation »).
- R3 : supprimer puis recréer le favori ARENA : cliquer sur [Gérer mes favoris], sélectionner iPackEPS professeur dans sa rubrique, valider, revenir à l'accueil ; iPackEPS apparaît dans [Mes favoris] et le clic sur ce lien rétablit l'accès.

### [SITUATION: iPackEPS FONCTIONNE-T-IL SUR MAC, TABLETTE OU PC ? FAUT-IL L'INSTALLER OU LE METTRE À JOUR ? QUELLE VERSION ?]
- Mots-clés : Mac, Apple, Windows, PC, tablette, iPad, installer, installation, télécharger, mise à jour, version, version minimale, navigateur, application en ligne, double-clic, ne se lance pas.
- Formulations courantes des collègues : est-ce que iPackEPS fonctionne sur Mac ; faut-il installer iPackEPS sur mon ordinateur ; comment mettre à jour iPackEPS ; quelle version d'iPackEPS faut-il ; quelle version minimale d'iPackEPS faut-il pour l'interfaçage avec Cyclades et Santorin ; iPackEPS ne se lance pas quand je double-clique.
- Réponse courte : OUI, iPackEPS fonctionne sur Mac comme sur PC, car ce n'est pas un logiciel à installer : c'est une application en ligne, que l'on ouvre dans un navigateur internet depuis le portail de son académie (ARENA).
- Il n'y a donc rien à télécharger, rien à installer et aucune mise à jour à faire soi-même : tout le monde utilise automatiquement la version en cours, et il n'existe pas de « version minimale » à vérifier. Cela vaut aussi pour l'interfaçage avec Cyclades et Santorin : aucune version particulière d'iPackEPS n'est à installer pour exporter vers Cyclades.
- Si iPackEPS ne s'ouvre pas, le problème vient de l'accès (portail, identifiants, application absente du portail) et non de l'ordinateur : voir les fiches sur les problèmes d'accès.

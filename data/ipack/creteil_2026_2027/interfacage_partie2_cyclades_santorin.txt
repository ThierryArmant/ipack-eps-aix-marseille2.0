### Examens : les saisies dans Cyclades et Santorin après iPackEPS (document officiel 2026-2027, partie 2)
[PORTEE: gt, pro, cap]
Réponse directe — l'ordre des étapes (à partir de janvier, après validation des protocoles par la commission académique) : 1) importer dans Cyclades le fichier d'élèves généré par iPackEPS (portail chef d'établissement) ; 2) vérifier l'affectation des élèves à leur protocole : Cyclades, menu [EPS] / [Associer les élèves à un protocole] (chef d'établissement et enseignant) ; 3) créer dans Imag'in une mission d'évaluation pour chaque enseignant (chef d'établissement) ; 4) dans Santorin, distribuer les élèves dans les lots de correction : menu [Distribution] / [Distribuer], distribution automatique (chaque protocole devient un lot) ou manuelle pour les cas particuliers ; 5) saisir les notes : menu [Distribution] / [Lots], élève par élève, répartition des points par AFL ou AFLP (enseignant ou référent établissement) ; 6) vérifier qu'aucun élève n'est resté sans protocole ni lot ; 7) verrouiller les lots.
Réponse directe — si les données ont été bien saisies dans iPackEPS, l'accès à Cyclades n'est normalement pas nécessaire pour les enseignants : tout a été transféré. Cyclades sert à gérer les protocoles et la répartition des élèves, Santorin à saisir les notes.
Élèves sans groupe dans Cyclades : des écarts entre iPackEPS et Cyclades sont fréquents (changement d'établissement en cours d'année) ; les élèves absents d'iPackEPS apparaissent sans groupe élève : les placer manuellement dans le bon groupe sur Cyclades. Si les groupes n'ont pas été importés avant, tous les élèves apparaissent sans protocole et doivent être réaffectés manuellement.
Changement d'enseignant : Cyclades, menu [EPS] / [Contrôler / Réaffecter des protocoles] (chef d'établissement), utile seulement si l'enseignant d'un protocole a été remplacé.
Nouveau protocole en cours d'année : Cyclades, menu [EPS] / [Créer un protocole] (chef d'établissement) ; on peut à tout moment créer un protocole de type adapté, notamment pour des élèves blessés, et il faut créer des protocoles adaptés pour les sportifs de haut niveau. Pour un nouveau protocole standard après validation : demander à la commission académique d'invalider les protocoles, créer le protocole en choisissant [standard], revenir à [EPS] / [Tableau de Bord], cliquer [OUI] dans [soumettre les protocoles], [Enregistrer], puis prévenir la commission qu'elle peut revalider.
Déplacer des élèves d'un lot à un autre : Santorin, menu [Distribution] / [Lots] (chef d'établissement), sans passer par Cyclades. Enseignant qui ne peut pas saisir ses notes : le chef d'établissement affecte dans Santorin un autre collègue ou se déclare lui-même évaluateur (il doit alors se créer une mission d'évaluation EPS dans Imag'in).
Cas exceptionnels (évaluation sur une ou deux APSA pour une raison externe : installation indisponible, professeur absent non remplacé) : tutoriel dédié, article 95.
Dernières vérifications avant verrouillage (chef d'établissement) : Cyclades, [EPS] / [Associer les élèves à un protocole] et Santorin, [Distribution] / [Voir infos Candidats] : plus aucun élève en attente d'attribution de protocole, tous dans un lot (les changements d'établissement ou de filière créent des incohérences).
Verrouillage : Santorin, [Saisie des Notes] / [Verrouiller] (enseignant ou référent établissement), bouton en haut à droite après saisie de toutes les notes. « Seul le chef établissement peut déverrouiller des lots. »
Statistiques : module simplifié pour l'enseignant, module avancé (par APSA, par genre…) pour le chef d'établissement et le référent établissement. Export du fichier de notes : [Correction] / [statistiques] / [générer le fichier Excel des notations] (chef d'établissement), demandé seulement dans certaines académies ; il permet aussi de repérer les notes [DI] pour vérifier les certificats médicaux (Santorin ne propose pas d'extraction directe des dispensés, article 75).
Accès : Cyclades et Santorin depuis le portail académique (ARENA ; à Aix-Marseille, le portail ESTEREL) ; pour quelques établissements privés, par un lien Imag'in transmis par la division des examens.
CFA, AEFE et établissements sans élèves dans iPackEPS : quatre étapes, toutes dans Cyclades, Imag'in et Santorin : 1) associer les élèves à leur groupe / protocole dans Cyclades (créer un protocole ou réaffecter un enseignant si besoin) ; 2) créer la convocation de l'enseignant pour la mission d'évaluation CCF EPS dans Imag'in ; 3) distribuer les lots de correction ; 4) saisir les notes.
Nature de la source : documentation officielle de l'application (assistance iPackEPS, académie de Créteil), version minimale 2026.2.x ; le document précise que les procédures Cyclades / Santorin peuvent encore évoluer légèrement.
Sources : « Interfaçage iPackEPS / Cyclades, partie 2 : les saisies sur Cyclades / Santorin », 2026-2027, et « C.F.A. : les démarches en ligne pour le CCF EPS », article 62 : https://ipackeps.ac-creteil.fr/spip.php?article62 ; article 75 : https://ipackeps.ac-creteil.fr/spip.php?article75 ; article 79 : https://ipackeps.ac-creteil.fr/spip.php?article79 (lus le 3 novembre 2026).

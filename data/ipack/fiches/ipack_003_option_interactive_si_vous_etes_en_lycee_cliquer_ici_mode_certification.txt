### [OPTION INTERACTIVE : SI VOUS ÊTES EN LYCÉE (CLIQUER ICI / MODE CERTIFICATION)]
- Mots-clés : suite lycée, étape apres edt lycée, ccf, fiches certificatives, fca, depot referentiels, cahn, cyclades, santorin, bac general, bac technologique, bac pro, cap.
- Portée : préparation du dossier certificatif du lycée (bac GT, bac pro, CAP). Les actions ci-dessous sont distinctes ; appliquer leurs conditions, sans en déduire une obligation uniforme pour les aménagements, l'EPPCS ou les autres académies.

1. Vérification et validation des protocoles d'évaluation (CCF) :
   - Chemin : [Tableau de bord] => [Dossiers] => [Dossier Certificatif] => [Protocoles d'évaluation].
   - Règle d'or : L'application croise groupes et programmations. Vérifier la conformité des ensembles certificatifs : 
     * Voie GT et Pro : Ensemble ordinaire : 3 APSA relevant de 3 Champs d'Apprentissage (CA) distincts.
     * Voie CAP : Ensemble ordinaire : 2 APSA relevant de 2 Champs d'Apprentissage (CA) distincts.
   - Branches adaptées ou aménagées : examiner leurs règles propres avant de conclure à un nombre d'épreuves obligatoire ; le cadre ordinaire ne suffit pas à rejeter un protocole adapté. Lire le message d'erreur avant de modifier le groupe ou sa séquence.

2. Dépôt des référentiels (Fiches Certificatives d'Activités - FCA) :
   - Chemin : [Tableau de bord] => [Dossiers] => [Dossier Certificatif] => [Référentiels].
   - Action conditionnelle : déposer le référentiel d'établissement attendu dans [Dépôt Référentiels Certificatifs], avec [Envoyer]. Pour une APSA reconnue de la liste académique, l'établissement n'a pas de référentiel à déposer : le référentiel académique fait référence. La visibilité de l'APSA ne prouve pas un dépôt obligatoire.
   - Vocabulaire : AFL pour le bac GT ; AFLP pour la voie professionnelle et le CAP. L'EPPCS suit sa branche propre et ne doit pas être assimilé à la certification de l'enseignement commun.

3. Soumission du dossier à la Commission Académique (CAHPN) (article 45) :
   - Chemin : depuis le [Dossier Certificatif], ouvrir la fenêtre de validation du dossier.
   - Action : cliquer sur [vérification], placer le curseur sur [OUI], ajouter un commentaire si des alertes subsistent, puis [enregistrer]. Le dossier est alors soumis à validation, même avec des alertes.
   - Les documents pour la commission (fiche établissement, fiches individuelles, certificats médicaux) se déposent dans [Dossier Certificatif] => [Dépôt des documents CAHPN] (articles 83 à 85).

4. Gestion des cas particuliers et inaptitudes permanentes :
   - Vérifier le rattachement des certificats médicaux pour les inaptitudes de l'année ou les demandes d'épreuves adaptées dans [Mes Élèves] => [Visualisation] => [Inaptitudes].
   - Déposer les fiches individuelles spécifiques (cas complexes d'élèves) si demandées par l'académie.

5. Export des groupes pour Cyclades :
   - Quand, circuit Aix-Marseille : après validation et dépôt des protocoles dans Cyclades par l'inspection ET import des candidats dans Cyclades par la DIEC. Le calendrier dépend de l'académie ; ne pas fixer janvier comme date universelle.
   - Chemin : [Tableau de bord] => [Dossiers] => [Dossier Certificatif] => [Cyclades].
   - Actions distinctes : dans iPackEPS, [Cyclades] > [Export Elèves] > [Exporter les Elèves] génère le fichier des groupes et élèves ; l'importation de ce fichier dans Cyclades est une opération séparée du circuit d'établissement. Le relevé de l'espace professeur n'établit pas un droit exclusif du chef ou de son secrétariat à générer le fichier. Ne pas l'ouvrir dans un tableur.
   - Fin de chaîne (hors iPackEPS) : le chef d'établissement distribue les lots de candidats dans Santorin, puis les enseignants y saisissent les notes.

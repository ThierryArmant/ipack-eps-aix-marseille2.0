### [ARTICLE 31] [Dossiers]/[Dossier SSS]/[Projet] Saisie du Projet Annuel de Section Sportive Scolaire
- Mots-clés : projet annuel SSS, section sportive scolaire, signature, [Enregistrer (brouillon)], groupe de type SSS, section absente, année précédente, bilan SSS, changer l’année scolaire
- Formulations courantes des collègues : Ma section sportive n’apparaît pas dans le projet annuel ; Comment modifier un projet SSS déjà signé ? ; J’ai oublié le projet ou le bilan SSS de l’an dernier, comment le compléter ? ; Où saisir le projet annuel de section sportive ? ; Comment récupérer le projet SSS de l'an dernier pour la nouvelle année ? ; Comment importer les données de la saisie de l'année précédente dans le projet de section sportive ? ; Le projet SSS est-il reconduit d'une année sur l'autre ?
- URL: spip.php?article31
- Texte: Accès à cette fonctionnalité : Tableau de bord => Les Dossiers et Projets ==> Dossier Section Sportive Scolaire ==> Projet Annuel.
- QUESTIONS / RÉPONSES [CONTEXTE STRICTEMENT SSS] :
  - Q1 : Mon chef d'établissement a signé le projet annuel SSS, mais je veux y apporter des modifications. Comment réactiver la modification ?
  - R1 : Il suffit de demander au chef d’établissement de réouvrir le dossier, et de cliquer en bas de la fenêtre sur le bouton [Enregistrer (brouillon)]. Ceci supprimera sa signature. Vous pourrez alors modifier le document.
  - Q2 : Je veux créer mon projet SSS, mais ma section sportive n’apparaît pas dans le module [Projet Annuel SSS] ?
  - R2 : Les rubriques [Projets Annuels SSS] et [Bilan SSS] ne sont actives que si iPackEPS trouve au moins un groupe de type SSS dans l’établissement. L’équipe doit donc configurer l’intégralité du Dossier EPS avant de se pencher sur le Projet de Section. Car le projet de section va reprendre la liste des élèves placés dans la SSS, les créneaux de SSS trouvés dans l’emploi du temps, les profs qui encadrent, etc… Donc si une équipe tente de saisir un projet SSS avant d’avoir finalisé le dossier EPS (groupes, APSA, élèves, équipements sportifs, EDT), le projet SSS sera incomplet.
  - Q3 : J’ai oublié de saisir mon projet ou mon bilan de SSS pour l’année précédente, comment compléter les informations ?
  - R3 : Il suffit, depuis le tableau de bord, de modifier l’année scolaire. Vous pourrez ensuite retourner dans [dossiers] / [dossier SSS] / [projet (ou bilan)], et vous retrouverez les projets et bilans de l’année dernière pour les compléter. Le chef d’établissement fera la même manipulation pour pouvoir signer ces documents.
  - Q4 : Le projet de section sportive a été déposé l'an dernier sur iPackEPS. Comment récupérer ou importer ces saisies pour le projet de la nouvelle année ?
  - R4 : Le projet annuel SSS se saisit pour chaque année scolaire. Pour la nouvelle année, iPackEPS reprend automatiquement dans le projet ce qui vient du Dossier EPS de l'année en cours : les élèves placés dans le groupe de type SSS, les créneaux SSS de l'emploi du temps et les professeurs qui encadrent. Il faut donc d'abord configurer le Dossier EPS de la nouvelle année (groupe de type SSS, APSA, élèves, emploi du temps). Le projet de l'an dernier reste consultable : depuis le tableau de bord, changez l'année scolaire pour revenir à l'année précédente, ouvrez [Dossiers] / [Dossier SSS] / [Projet] et reprenez-en le contenu, puis revenez sur l'année en cours pour saisir le nouveau projet. La documentation iPackEPS ne décrit pas de bouton de copie automatique d'un projet SSS d'une année sur l'autre. Ne pas confondre avec la question Q3, qui sert uniquement à compléter un projet oublié l'année précédente. Tutoriel : Projet_annuel_SSS.mp4.

### [ARTICLE 111] SECTIONS SPORTIVES SCOLAIRES (SSS), CLASSES SPORTS-ÉTUDES ET SPORTIFS DE HAUT NIVEAU (SHN) : NE PAS LES CONFONDRE
- Mots-clés : sport étude, classes sports-études, section sportive, SSS, SHN, sportif de haut niveau, pôle espoir, haut niveau, différence, confusion.
- Formulations courantes des collègues : quelle différence entre section sportive et sports-études ; où déclarer ma classe sports-études ; où gérer ma section sportive ; mon élève est sportif de haut niveau, est-ce une section sportive ?
- Ce sont TROIS sujets distincts. Déterminer lequel correspond à la question avant de répondre et de proposer une vidéo.
- 1. CLASSES SPORTS-ÉTUDES : module [Dossiers] > [Dossier Sports-Études] (Article 91). On y dépose le projet de la classe et on y voit les groupes de type sports-études déjà déclarés. Ces groupes se créent dans [Dossiers] > [Dossier EPS] > [Groupes] en choisissant le type sports-études. 📺 Vidéo pour ce cas uniquement : "Configurer_Classes_Sports_Etudes.mp4".
- 2. SECTIONS SPORTIVES SCOLAIRES, DOSSIERS ADMINISTRATIFS : module [Dossiers] > [Dossier SSS], avec quatre modules : demande d'ouverture (Article 28), projet annuel (Article 31), bilan annuel (Article 39), évolution c'est-à-dire reconduction ou fermeture (Article 94). Chaque dossier est signé par le chef d'établissement. 📺 Vidéos pour ce cas uniquement, selon le module : "Configuration_modules_SSS.mp4" (présentation), "Demande_ouverture_SSS.mp4", "Projet_annuel_SSS.mp4", "Bilan_annuel_SSS.mp4", "Evolution_et_fermeture_SSS.mp4".
- 3. SECTIONS SPORTIVES SCOLAIRES, GROUPES DE L'ANNÉE EN COURS : cela ne se fait pas dans le Dossier SSS mais dans [Dossiers] > [Dossier EPS] > [Groupes], avec un groupe de type SSS (Article 17), puis placement des élèves dans [Dossiers] > [Dossier EPS] > [Élèves] (Article 18). Un groupe SSS ne peut être associé qu'à une seule APSA : pour une section qui travaille plusieurs activités, créer manuellement une APSA portant le nom de l'ensemble (exemple : « Football-Musculation ») dans [Dossiers] > [Dossier EPS] > [APSA]. Les groupes ne sont pas reconduits d'une année sur l'autre : ils sont à reconfigurer à chaque rentrée et les élèves à y replacer ; la liste des APSA, elle, est conservée. 📺 Vidéo pour ce cas uniquement : "Gestion_groupes_iPackEPS.mp4".
- 4. SPORTIFS DE HAUT NIVEAU (SHN) : c'est un statut individuel d'élève pour l'examen, pas une classe ni une section. Voir l'Article 112. Aucune vidéo Sports-Études ni SSS à proposer pour ce cas.

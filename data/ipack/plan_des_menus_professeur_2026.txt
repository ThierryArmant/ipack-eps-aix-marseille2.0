### [SITUATION: PLAN DES MENUS D'iPackEPS — ESPACE PROFESSEUR (version 2026.2.1.1)]
- Mots-clés : où trouver, dans quel menu, chemin, plan des menus, tableau de bord, module, rubrique, onglet.
- Formulations courantes des collègues : où se trouve ; dans quel menu ; je ne trouve pas la rubrique ; comment accéder à ; c'est où dans iPackEPS.
- Réponse directe : depuis le [Tableau de bord], sept rubriques : [Établissement], [Ma Fiche Professeur], [Les Dossiers et Projets], [Mes Élèves], [Mes Documents], [Gestion du Matériel], [Statistiques et Offre de Formation], plus [Outils] ; les chemins ci-dessous sont ceux affichés par l'application.
- [Établissement] : Coordonnées ; Contacts ; Visite IA-IPR ; Configuration ; Gestion EPI ; Gestion AS.
- [Ma Fiche Professeur] : Statut ; Service ; Fonctions ; Compétences Particulières ; Spécialités Sportives ; Vœux de Jury ; Vœux de Formation ; Informations Inspection.
- [Les Dossiers et Projets] : Dossier EPS ; Dossier Certificatif (lycées, désactivé pour un établissement sans certification) ; Dossier Natation ; Dossier Section Sportive Scolaire ; Dossier Équipements ; Dossier APPN ; Dossier Sport-Études.
- [Dossier EPS] : Projets (Projet Établissement, Projet EPS, Projet AS, Projet SSS) ; Équipe EPS et Intervenants Extérieurs (Membres de l'équipe, Fonctions, Bilan ; boutons [Actualiser] et [Nouvel Intervenant]) ; Classes (Configuration des Classes, Organisation des Classes, Importation des Élèves) ; APSA (APSA de collège ou voie professionnelle, APSA de lycée général ou technologique) ; Périodes ([Créer une nouvelle Période]) ; Groupes ; Élèves (placement des élèves dans les groupes, [Importer un fichier d'élèves] CSV Pronote ou École Directe) ; Équipements Sportifs ; Emplois du temps (Agenda Équipe, Édition Créneaux, Vérification Agenda).
- [Dossier EPS] > [Groupes], types de groupes : Groupes EPS ; Enseignement Optionnel ; Enseignement de Spécialité ; Groupes AS ; Sections Sportives Scolaires ; UF2S ; Sport-Études ; Accompagnement Personnalisé (support APSA) ; Accompagnement Personnalisé (sans APSA) ; Autres Dispositifs Sportifs ; Divers sans APSA ; boutons [Créer un groupe] et [Gérer les S.A.] (séquences d'apprentissage).
- [Dossier Natation] : Validation ASNS (consulter, imprimer les validations des élèves) ; Saisie de l'enquête (enquête natation) ; Statistiques Enquête.
- [Dossier Section Sportive Scolaire] : Projet Annuel SSS ; Bilan Annuel SSS ; Évolution SSS (demande de fermeture ou de reconduction).
- [Dossier Équipements] : Saisie de l'enquête (enquête équipements) ; Équipements Sportifs (même page de gestion que [Dossier EPS] > [Équipements Sportifs]).
- [Dossier APPN] : demande de validation d'un projet pédagogique en APPN à environnement spécifique (EPS, AS, SSS, enseignement facultatif ou projet spécifique), référence circulaire n° 2017-075 ; choisir l'activité, préciser le détail (exemple : ski de randonnée, kayak rivière), [Créer] ; le tableau des demandes indique l'état, les dates, la date de signature du chef d'établissement, la date de fin de validité et le commentaire académique.
- [Dossier Sport-Études] : un établissement est reconnu Sport-Études dès qu'un groupe de type Sport-Études est créé ou qu'un projet Sport-Études est déposé ; dépôt du projet sur cette page ; les groupes se déclarent dans [Dossier EPS] > [Groupes].
- [Mes Élèves] : Visualisation (parcours des élèves) ; Inaptitudes (liste des élèves déclarés inaptes).
- [Mes Documents] : Documents (Bordereaux Évaluations, Programmation, Dossards) ; Publipostage (documents personnalisés : convocations, diplômes…) ; Bibliothèque (documents à consulter et télécharger).
- [Gestion du Matériel] : Inventaire EPI (boutons [Créer un Matériel], [Imprimer le Cahier de Suivi (pdf)], [Nouveau Contrôle], [Mettre à l'écart], [Mettre au Rebut (Destruction)]) ; Inventaire Matériel Divers ; Configuration Matériel Divers.
- [Statistiques et Offre de Formation] : Groupes et APSA (groupes et APSA programmés dans l'académie) ; Statistiques Inaptitudes (bilan de l'établissement).
- [Outils] : Export Fichier Élèves vers un autre logiciel ([Exporter]).
- En bas de chaque page : Site d'Assistance, Playlist des tutoriels, Écrire au support académique. Le lien « Playlist des tutoriels » ouvre la liste de lecture YouTube des tutoriels iPackEPS : https://www.youtube.com/playlist?list=PLI9OmEQb8i20YTYsAkPbGTcKHBadQxynq (lien relevé sur la page le 18 octobre 2026) ; « Site d'Assistance » ouvre https://ipackeps.ac-creteil.fr. Sur la page d'accueil, si un établissement « n'a pas été trouvé dans la base de données », contacter le support technique si l'on a des heures d'EPS dans cet établissement.
- Nature : fonctionnement du logiciel, relevé à l'écran dans l'espace professeur d'un collège (version 2026.2.1.1, 18 octobre 2026) ; un lycée voit en plus le Dossier Certificatif actif et les APSA de lycée. Les libellés peuvent évoluer avec les versions.

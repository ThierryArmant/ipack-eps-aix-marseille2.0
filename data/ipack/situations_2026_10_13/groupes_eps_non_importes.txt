### iPackEPS : les élèves sont importés, mais pas les groupes EPS
[PORTEE: gt,pro,cap,dnb]
Sigles : SIECLE = système d'information de la base élèves des établissements ; BEE = base élèves établissement ; AS = association sportive.
L'import des élèves depuis la base élèves remplit les classes configurées dans iPackEPS. Les groupes EPS (menus de terminale, groupes d'AS, savoir-nager…) se créent dans iPackEPS, puis on y place les élèves.
1. Créer les groupes : [Dossiers] / [Dossier EPS] / [Groupes], en choisissant le type (Groupes EPS, Enseignement Optionnel, Enseignement de Spécialité, Groupes AS, Sections Sportives Scolaires, UF2S, Sport-Études).
2. Placer les élèves : [Dossiers] / [Dossier EPS] / [Élèves], fenêtre « Placement des Élèves dans les Groupes ».
3. Si les élèves sont déjà répartis dans des groupes sur Pronote, extraire ces groupes depuis Pronote et les importer avec le bouton [Import Pronote] (« Importer un fichier d'élèves de Pronote (CSV) ») ; le fichier attendu est au format .csv. À partir de la version 2025.3.1, les fichiers d'École-Directe (établissements privés) sont aussi acceptés.
Un fichier exporté de la base élèves (lien élève-groupe) n'est pas un format d'import décrit dans la documentation d'iPackEPS : utiliser l'import Pronote ou École-Directe, ou le placement manuel ; en cas de doute, contacter l'assistance iPackEPS de l'académie.
Avant l'export vers Cyclades, vérifier qu'aucun élève de classe à examen n'est resté sans groupe EPS : iPackEPS affiche une alerte « élèves sans groupe EPS ».
Nature de la source : fonctionnement du logiciel iPackEPS (documentation de l'éditeur).
Sources : « Nouvelles Fonctionnalités 2025-2026 », iPackEPS version 2025.3.x ; guide iPackEPS, articles 14, 17 et 18 (classes, groupes, placement des élèves).

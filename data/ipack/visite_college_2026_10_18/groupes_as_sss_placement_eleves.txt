### iPackEPS : créer un groupe (AS, section sportive…) et y placer les élèves
Réponse directe — « je ne vois pas mes élèves pour faire mon groupe d'AS » ou « mon groupe n'apparaît pas pour placer les élèves » : si le groupe a bien été créé dans [Dossier EPS] > [Groupes], il apparaît dans le panneau de droite de [Dossier EPS] > [Élèves] ; dans le panneau de gauche, la liste reste vide tant qu'on n'a pas choisi le filtre : Visualisation « Classes », puis le niveau (Type), puis la classe (Sélection) ; si un élève manque, refaire l'import dans [Classes] > [Importation des Élèves] > [Importer].
Étape 1 — créer le groupe : [Dossier EPS] > [Groupes] > onglet du dispositif ([Groupes AS], [Sections Sportives Scolaires], [Autres Dispositifs Sportifs]…) > [Créer un groupe] : nom du groupe (par exemple « AS Tir à l'arc ») et professeur ; message « Groupe enregistré ». Écran : « Pensez à renseigner la séquence d'apprentissage associée à chaque groupe d'AS » : [Gérer les S.A.] avec la période [Année].
Étape 2 — placer les élèves : [Dossier EPS] > [Élèves] (« Placement des Élèves dans les Groupes ») : à droite, choisir le groupe de destination ; à gauche, filtrer (Classes → niveau → classe) ; cocher les élèves (la case en tête de colonne les sélectionne tous ; pour l'AS, ne cocher que les élèves concernés) ; cliquer sur [Ajouter -->] ; [<-- Enlever] pour retirer un élève.
Autre possibilité affichée à l'écran : si les groupes existent déjà dans Pronote ou École Directe, les extraire et les importer avec [Importer un fichier d'élèves (CSV Pronote/École-Directe…)].
Section sportive scolaire (texte de l'écran) : « seuls les groupes SSS validés par le recteur doivent être saisis ici » ; une seule APSA par groupe SSS : pour une section à plusieurs activités, créer une APSA combinée (par exemple [Football-Musculation]) dans [Dossier EPS] > [APSA] ; les dispositifs qui ne sont pas une SSS officielle vont dans [Autres Dispositifs Sportifs].
Règle générale : si une étape n'a pas été faite dans l'ordre, revenir en arrière la compléter avant de continuer (Classes → APSA → Périodes → Groupes → Élèves).
Parcours guidé : [Dossier EPS] → [Groupes] → [Groupes AS] → [Créer un groupe] → [Élèves] → filtre Classes → [Ajouter -->].
Nature de la source : fonctionnement du logiciel iPackEPS (espace professeur, version 2026.2.1.1), relevé à l'écran avec le correspondant académique iPackEPS ; fonction commune à toutes les académies.
Source : visite guidée de l'espace professeur iPackEPS (collège) avec le correspondant académique iPackEPS, 18 octobre 2026 ; textes affichés à l'écran cités entre guillemets.

### iPackEPS lycée : déclarer une APSA certificative et construire le protocole d'examen d'un groupe
Réponse directe — APSA certificative : [Dossier EPS] > [APSA] > [APSA de Lycée Général ou Technologique] ; dans « APSA retenues dans votre établissement », crayon [Modif.] sur l'APSA : fenêtre « Configuration d'une APSA » : « VOIE G.T. » OUI/NON, champ d'apprentissage (C.A. 1 à 5), « APSA Étab », « Certificative » OUI/NON, « Certificative Adaptée » OUI/NON, puis [Enregistrer]. Colonnes de la liste : APSA Étab, Certif Lyc, Ada. Lyc, C.A. Lyc.
Réponse directe — classes d'examen, deux contextes (correspondant académique iPackEPS) : 1) établissement de l'Éducation nationale : importer les classes puis définir leur organisation ([Dossier EPS] > [Classes] : [Actualiser], [Configuration des Classes], [Organisation des Classes] avec le mode et les professeurs, [Importation des Élèves]) : les classes d'examen doivent être organisées ; 2) établissement hors Éducation nationale (CFA, MFR, établissement AEFE à l'étranger) : il ne passe pas par [Classes] ; il va directement dans [Dossier EPS] > [Groupes] créer ses groupes ([Créer un groupe], puis [Gérer les S.A.]).
Explications du correspondant académique iPackEPS (18 octobre 2026) — les trois étapes de l'examen :
Étape 1 — [Dossier EPS] > [Classes] : [Actualiser] fait remonter les classes dans iPackEPS ; dans [Organisation des Classes], on définit pour chaque classe comment elle est organisée en EPS : « Mode Seul ou Mixte », ou « Mode Groupe » quand elle est associée à d'autres classes (menus).
Étape 2 — [Dossier EPS] > [Groupes] > [Gérer les S.A.] : on compose les ensembles certificatifs en définissant les APSA et les périodes d'enseignement.
Étape 3 — [Les Dossiers et Projets] > [Dossier Certificatif] > [Protocole d'Évaluation des Épreuves Certificatives] : choisir l'examen concerné ; ce qui a été fait dans [Groupes] remonte ici comme protocole ; pour chaque APSA, ajouter une date d'évaluation, une date de rattrapage et un co-évaluateur. Le co-évaluateur n'est obligatoire que pour la voie générale.
Réponse directe — protocole valide : les protocoles ne sont valides que lorsque les icônes sont des coches vertes. Deux colonnes : 1) Validité : s'appuie sur la composition du protocole (respect de la réglementation, nombre d'épreuves : 3 pour le baccalauréat, 2 pour le CAP) ; une coche verte confirme que le protocole est complet, sinon une autre icône apparaît ; 2) Référentiel : validité des référentiels d'appui (référentiels déposés et validés par la commission académique).
Réponse directe — placer les élèves dans un groupe d'examen : [Les Dossiers et Projets] > [Dossier EPS] > [Élèves] ; à gauche, Visualisation « Classes », puis la ou les classes souhaitées ; à droite, Type « EPS » et le groupe créé ; cocher les élèves à basculer, puis [Ajouter -->] : ils passent dans le groupe.
Réponse directe — trouver les élèves sans groupe : dans [Élèves], panneau de gauche « Placer les élèves du groupe… », Visualisation « Statut », puis dans Type le statut des élèves sans groupe : tous les élèves qui ne sont dans aucun groupe s'affichent, ce qui permet de les affecter ; la liste « Sélection » permet d'affiner au besoin. Le bilan Cyclades nomme ce statut « Sans Groupe EPS ».
Voie professionnelle et CAP : même démarche (correspondant académique) ; les APSA se déclarent dans [Dossier EPS] > [APSA] > [APSA de Collège ou Voie Professionnelle] (intitulé relevé à l'écran).
Ajouter une APSA à la liste : trois listes avec le bouton « + » : « Liste Nationale d'APSAs », « Liste Académique d'APSAs », « Liste Prédéfinie d'APSAs (si votre APSA n'est pas trouvée dans la liste nationale ou académique, cherchez-la ici… créez une nouvelle APSA si elle n'est pas trouvée également dans la liste prédéfinie) » ; sinon [Créer une APSA].
Réponse directe — protocole d'examen d'un groupe : [Dossier EPS] > [Groupes] > [Groupes EPS] > [Gérer les S.A.] sur le groupe : fenêtre « Gestion des Séquences d'Apprentissage » ; « Sélectionnez une APSA… », puis répondre à « indiquez si l'APSA sera certifiée dans le cadre de l'examen. Les élèves seront évalués sur cette APSA pour l'examen » (OUI/NON) ; « Sélectionnez la Période de pratique… » (dates) ; [Ajouter]. La même fenêtre affiche l'« État du Protocole » (par exemple « Le protocole est valide ») et, pour chaque séquence, les colonnes adaptée, référentiel et certifiable.
Raccourci affiché : « Vous pouvez importer les Séquences d'Apprentissage déjà définies dans un groupe de même type… » (liste « Sélectionnez un groupe… »).
Seules les séquences évaluées pour l'examen comptent dans le protocole : voir aussi l'article 17 de l'assistance (nombre de séquences certificatives par groupe).
Onglets [Enseignement Optionnel] et [Enseignement de Spécialité] : « Renseignez ici vos groupes de type [enseignement optionnel] / [enseignement de spécialité] (cf. Bulletin officiel n°25 du 24 juin 2021) » ; [Créer un groupe].
Ensuite : [Dossier Certificatif] (référentiels, dates d'épreuves, export vers Cyclades).
Parcours guidé : [Dossier EPS] → [APSA] → [APSA de Lycée Général ou Technologique] → crayon [Modif.] → « Certificative » OUI → [Enregistrer] → [Groupes] → [Gérer les S.A.] → [Ajouter].
Nature de la source : fonctionnement du logiciel iPackEPS (espace professeur, lycée général et technologique, version 2026.2.1.1), relevé à l'écran en lecture seule ; fonction commune à toutes les académies.
Source : précisions du correspondant académique iPackEPS (18 octobre 2026) pour les deux contextes de classes ; visite de l'espace professeur iPackEPS d'un lycée général et technologique, 18 octobre 2026, avec un accès fourni par le correspondant académique iPackEPS ; textes affichés à l'écran cités entre guillemets ; aucun bouton d'enregistrement n'a été actionné.

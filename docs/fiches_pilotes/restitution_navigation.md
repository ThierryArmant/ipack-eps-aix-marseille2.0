# Aperçu de restitution des chemins cités

Dans l’administration, sous une réponse conservée, ouvrir le contrôle pilote. Choisir la fiche et les branches, puis « Prévisualiser les passages cités avec leur chemin — sans appel IA ». Il n’est pas nécessaire de reposer la question. Le résultat est séparé de la réponse et conservé dans `fiche_pilot_preview` de la trace téléchargeable.

Le prototype est vérifié contre son fichier d’origine. La restitution est proposée seulement pour une unité logicielle portant un chemin manquant, dans une branche choisie explicitement, lorsqu’une affirmation finale acceptée cite seule un passage exactement identique à cette unité. Ce passage doit apparaître dans les données réellement transmises au rédacteur et dans le document correspondant à la source du prototype. Le texte entier est recopié, sans recomposition, avec les mêmes preuves ; il ne s’agit pas d’ajouter un menu pris dans une autre branche.

Aucune restitution si la réponse contient déjà le chemin, si aucune affirmation n’a été acceptée, si les données transmises manquent, si la citation combine plusieurs passages, si l’extrait diffère, ou pour les unités académiques et réglementaires. Le réviseur doit toujours contrôler l’applicabilité, l’acteur et le sens. Le programme ne déduit pas que la condition du cadenas est établie.

Ce mécanisme ne répare pas automatiquement le texte affiché, ne modifie ni les fiches ni les consignes, et ne déclenche aucun appel IA ou enregistrement externe. Une proposition complète dans l’aperçu ne prouve pas la complétude des autres étapes. Les cas de navigation dont le prototype contient seulement un fragment d’un passage plus long ne sont volontairement pas traités ; ils nécessitent une revue du découpage avant généralisation.

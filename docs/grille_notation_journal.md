# Grille de notation des réponses du hub (échantillon du journal)

À utiliser pour noter `echantillon_a_noter.csv` (produit par `python3 outils/stat_journal.py export.csv sortie 200`). Noter **avant** toute correction, sans modifier les fiches pendant la notation.

## Verdict
- **correct** : la décision ou la démarche est exacte, utile et ne fait pas fausse route ; les sources citées la justifient. Une précision manquante mais signalée (« point non trouvé dans les sources ») reste correcte si le reste est juste.
- **partiel** : l'essentiel est juste, mais il manque une étape ou une condition importante, ou la réponse reste trop générale pour agir.
- **faux** : décision ou chemin erroné, règle inventée, prémisse fausse acceptée, mauvais public (règle de lycée appliquée au collège…), consigne d'une autre académie présentée comme générale.

## Gravité (pour les réponses partielles ou fausses)
- **0** : sans conséquence (formulation, détail).
- **1** : fait perdre du temps (mauvais menu, étape manquante).
- **2** : peut conduire à une erreur d'examen ou de réglementation (note, inaptitude, protocole, sécurité).

## Règles
- Juger avec les sources du hub et les textes officiels ; en cas de doute, noter « partiel » et écrire le doute dans le commentaire.
- Une demande de précision ou l'ouverture du guide pas à pas sur une question réellement imprécise compte comme **correct**.
- Ne recopier aucun nom d'élève ou de collègue dans les commentaires.
- Les questions déjà utilisées pour écrire les fiches donnent un résultat optimiste : le chiffre de fiabilité se confirme sur des questions nouvelles.
